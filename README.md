# GridGuard-RL

基于深度强化学习的高比例光伏配电网无功优化与安全控制项目，面向电力算法、强化学习与新能源控制实习展示。

**当前状态：已完成项目规划，尚未实现仿真、训练和正式评测。** 本仓库现阶段保存项目方案与协作规则，以下技术路线均为计划内容。

## 计划实现

- 基于 IEEE 33 节点与 pandapower 构建光伏、负荷时序仿真。
- 建立 Unity PF、Volt-VAR、DSG 基线，并实现 Gymnasium 环境与 SAC 控制。
- 实现设备能力约束、潮流异常检测及失败处理，进一步探索 DSG 引导的残差 SAC。
- 在独立测试场景下比较电压、网损、动作及失败指标，提供可复现的运行入口和真实结果。
